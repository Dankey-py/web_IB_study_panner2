01Where to start

A short guide to the files

These are a few useful places to look if you want to understand the implementation.

How tasks are ordered

In the backend, app.py combines priority and deadline urgency to suggest an order for unfinished tasks.

How an AI plan is reviewed

AssistantPanel.tsx contains the review interface. The backend checks the edited proposal before applying it.

How records are stored

schema.sql defines the database structure. database.py initialises the database.

02About this website

A separate project website

This website explains the planner. It uses HTML, CSS and a small amount of JavaScript, so it can be hosted on GitHub Pages.

The full planner needs its own frontend and backend. Setup instructions are in the repository READMEs.

The screenshots show dated development versions. The interactive example uses sample data and does not save anything to the real planner.

The application is still in development. Some changes shown here may be newer than the version uploaded to GitHub.
