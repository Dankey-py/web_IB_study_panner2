02ABOUT THIS SHOWCASE

A website about
the project.

This showcase is a separate set of HTML, CSS and JavaScript files. It needs no account, backend or AI key.

The full StudyOS planner requires its React frontend and Flask backend. Repository READMEs contain the application setup instructions.

Product images are dated development captures, reproduced in monochrome. The interactive review example is a simplified illustration, not the running application.

Source links use the project’s configured GitHub repositories. Screenshots and descriptions reflect local development; the latest local changes may not yet appear on GitHub.
